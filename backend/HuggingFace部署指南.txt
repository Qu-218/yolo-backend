===================================
暖记PLM 后端 - Hugging Face Spaces 部署指南
===================================

一、为什么选择 Hugging Face Spaces？
====================================

✅ 完全免费
✅ 不需要一直开着本地服务
✅ 支持 FastAPI + YOLOv8
✅ 自动构建和部署
✅ 提供免费域名：https://your-username.hf.space

二、部署步骤
============

1. 注册 Hugging Face 账号
   https://huggingface.co/join

2. 创建 Space
   - 访问：https://huggingface.co/new-space
   - 填写 Space 名称（如：warm-plm-backend）
   - 选择 SDK：Docker
   - 选择 Free tier
   - 点击 Create Space

3. 上传代码
   - 方式一：网页上传
     在 Space 页面点击 "Files" → "Add file" → "Upload files"
     上传 backend 目录下的所有文件

   - 方式二：Git 推荐（更方便更新）
     git clone https://huggingface.co/spaces/your-username/warm-plm-backend
     cd warm-plm-backend
     # 复制 backend 目录下的所有文件到此处
     git add .
     git commit -m "Initial commit"
     git push

4. 等待构建
   - Hugging Face 会自动构建 Docker 镜像
   - 构建时间约 5-10 分钟
   - 构建完成后自动部署

5. 访问 API
   - 访问：https://your-username-warm-plm-backend.hf.space
   - 健康检查：https://your-username-warm-plm-backend.hf.space/health
   - API 文档：https://your-username-warm-plm-backend.hf.space/docs

三、需要上传的文件
==================

backend/
├── main.py              # FastAPI主应用
├── enhance.py           # 低光照增强模块
├── utils.py             # 工具函数
├── requirements.txt     # Python依赖
├── Dockerfile           # Docker构建配置
├── README.md            # Space 配置文件（必需）
└── weights/
    └── yolov8n.pt       # YOLO模型权重

四、配置说明
============

Dockerfile 端口：7860（Hugging Face Spaces 默认端口）
环境变量：无需额外配置
资源限制：Free tier 提供 2 CPU + 16GB 内存

五、在小程序中使用
==================

部署完成后，将小程序中的后端地址改为：
https://your-username-warm-plm-backend.hf.space

例如：
const API_BASE = 'https://your-username-warm-plm-backend.hf.space';

六、更新代码
============

如果需要更新代码：
1. 修改本地文件
2. 推送到 Hugging Face（git push）
3. 自动重新构建和部署

七、注意事项
============

1. Free tier 限制：
   - CPU：2核
   - 内存：16GB
   - 存储：50GB
   - 无 GPU

2. 冷启动：
   - 首次访问可能需要等待几秒
   - 模型加载需要时间

3. 休眠机制：
   - 48小时无请求后休眠
   - 下次访问自动唤醒

============

   - 模型文件过大

Q: 如何查看日志？
A: 在 Space 页面点击 "Logs" 查看
